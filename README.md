# Jokenpô em Python


Projeto desenvolvido em **Python** como parte dos meus estudos de programação.

O programa simula uma partida de Jokenpô (Pedra, Papel e Tesoura), permitindo que o jogador escolha uma jogada enquanto o computador realiza sua escolha aleatoriamente.

## 🎮 Como funciona

O jogador pode escolher:

1. Pedra
2. Papel
3. Tesoura

O computador realiza uma jogada aleatória e o programa registra:

* Vitórias do jogador
* Vitórias do computador
* Empates
* Jogadas realizadas

## 📚 Conceitos praticados

* Funções
* `if`, `elif` e `else`
* Estruturas de repetição (`while` e `for`)
* Listas
* Validação de entrada
* Variáveis globais
* `random`
* Geração de números aleatórios
* Manipulação e exibição de dados
